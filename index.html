Key High-Performance Computing Findings:

  • Kernel Launch & Latency Hiding: At 128×128, kernel invocation and host-to-device memory copies dominate execution time, giving CPU an edge.
  • Massive Parallelism: Beyond 512×512, CUDA launches tens of thousands of simultaneous GPU threads. Each thread computes one cell update in coalesced 32-bit registers.
  • Shared Memory Tiling: Ghost cells and neighbor stencils are loaded into fast L1 shared memory tiles, avoiding repeated global VRAM transactions.
